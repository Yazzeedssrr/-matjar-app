# مَخْرَج — Feature Backlog

## تجربة العميل
- Onboarding اختياري سريع وتفضيلات العميل.
- بحث فوري + اقتراحات + سجل البحث + تصحيح الكلمات لاحقًا.
- فلاتر متعددة: السعر، التوفر، التقييم، التصنيف، اللون، المقاس.
- قوائم مفضلة متعددة بدل قائمة واحدة.
- مقارنة منتجات.
- شوهد مؤخرًا + متابعة التصفح من آخر مكان.
- مشاركة المنتج وروابط Deep Links.
- معرض صور/فيديو، Zoom، خيارات variants، دليل مقاسات.
- تقييمات ومراجعات وصور العملاء بعد ربط backend.
- أسئلة وأجوبة لكل منتج.
- تنبيه عند عودة المنتج للمخزون.
- تنبيه انخفاض السعر.
- Bundles / اشترِ معًا.
- هدايا وتغليف ورسالة هدية.
- حفظ السلة ومزامنتها عند تسجيل الدخول.
- كوبونات، Gift cards، Store credit.
- عناوين متعددة وتعليمات توصيل.
- طرق شحن متعددة وموعد توصيل تقديري.
- Checkout متعدد المراحل مع مراجعة نهائية.
- طلب كضيف أو بحساب.
- إعادة الطلب بنقرة.
- إلغاء/إرجاع/استبدال حسب حالة الطلب والسياسة.
- Timeline للتتبع + إشعارات تغيّر الحالة.
- مركز دعم: FAQ، تواصل، تذكرة دعم، مشكلة في طلب.
- مركز إشعارات داخل التطبيق.
- برنامج نقاط/مكافآت لاحقًا.
- إحالات ومشاركة كود دعوة لاحقًا.

## الجودة والتجربة
- Skeleton loading بدل الشاشات الفارغة.
- Offline states وRetry.
- Toast + Undo.
- Haptics حيث يدعم الجهاز.
- حفظ scroll/state.
- دعم Back الصحيح في Android.
- Reduced Motion وإمكانية الوصول.
- RTL أصلي، أحجام خط واضحة، contrast مناسب.
- Lazy loading وضغط الصور.
- Empty states مختلفة حسب السياق.
- Error boundary ورسائل أخطاء مفهومة.

## الإدارة
- Dashboard اليوم/الأسبوع/الشهر.
- المبيعات، متوسط قيمة الطلب، المنتجات الأعلى، العملاء العائدون.
- Queue للطلبات التي تحتاج إجراء.
- إدارة حالة الطلب وسجل تغييرات.
- إدارة المنتجات والصور والVariants وSKU والباركود.
- المخزون والتنبيهات والجرد والتعديلات.
- الأسعار والعروض والجدولة الزمنية للعروض.
- كوبونات بشروط وحدود استخدام.
- العملاء، تاريخ الطلبات، ملاحظات داخلية.
- شرائح العملاء وحملات لاحقًا.
- إدارة Banner/Collections من الإدارة.
- الشحن والمناطق والأسعار والحد المجاني.
- الضرائب عند تحديد نموذج العمل.
- مرتجعات واستبدالات واسترداد.
- تقارير وتصدير CSV.
- Audit log للأعمال الإدارية.
- صلاحيات متعددة للموظفين.

## البنية والأمان
- فصل storefront عن admin.
- Supabase Auth للإدارة.
- RLS لكل الجداول الحساسة.
- عدم تخزين service-role أو أسرار في العميل.
- Orders/Products/Variants/Inventory/Customers/Addresses/Coupons/Reviews/Notifications schema منفصل.
- Server-side validation للطلبات والأسعار والمخزون.
- Rate limits / abuse protection حيث يلزم.
- نسخ احتياطي وخطة استعادة قبل Production.

## Android / المتجر
- Adaptive icon وهوية Splash أصلية.
- Deep links للمنتجات والطلبات.
- Push notifications بعد backend.
- App Links.
- Offline shell.
- Signed AAB.
- Internal testing.
- Privacy Policy / Data Safety / Store Listing.
- Crash monitoring وanalytics بعد اختيار الأدوات.

هذا الملف Backlog حيّ؛ الميزات لا تُعتبر Production حتى تكون مرتبطة ببيانات حقيقية، مختبرة، ومؤمنة.
