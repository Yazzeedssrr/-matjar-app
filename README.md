# مَخْرَج | MAKHRAJ

الفرع الرسمي لتطوير مشروع المتجر الحالي إلى منتج احترافي قابل للتجهيز والنشر على Android.

## الهوية
- الاسم: مَخْرَج | MAKHRAJ
- الفكرة: النور في نهاية النفق، وبداية جديدة.
- الشعار النصي: دائمًا هناك مخرج.

## خطة التطوير
1. الحفاظ على النسخة الحالية على `main` دون كسرها.
2. تحديث هوية وتجربة متجر الزبائن.
3. فصل وتأمين وظائف الإدارة.
4. تنظيم الاتصال بـ Supabase وسياسات الصلاحيات.
5. إضافة PWA وملفات الهوية اللازمة.
6. إضافة مشروع Android وتجهيزه للبناء بصيغة AAB.
7. إضافة فحوصات بناء تلقائية قبل الدمج والنشر.

> التطوير يتم أولًا على فرع `makhraj-android` ثم يراجع قبل دمجه إلى `main`.
